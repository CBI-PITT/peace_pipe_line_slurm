# analysis_pipeline
Utils for brain registration, spot counting and analysis automation

`conda create -y -n cellfinder python=3.8`<br/>
`conda activate cellfinder`<br/>
`pip install -r requirements.txt`<br/>
`python scan_for_ims.py` or `python scan_for_ims.py ignore_processed`<br/>
(with `ignore_processed` all previous processing will be overwritten)
